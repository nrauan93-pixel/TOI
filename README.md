# Toi Bot 🎉

Telegram-бот для выбора зала и тамады для тоя: цены, отзывы, расстояние до вас и подбор по бюджету в одном месте.

🤖 **Бот:** https://t.me/toi3_bot
☁️ **Хостинг:** Railway, бот работает 24/7 на сервере, без запущенного локального кода

## Идея

Чтобы организовать той, приходится сравнивать залы по ценам и отзывам и искать тамаду по Instagram и чатам. Бот собирает всё это в одном месте.

## Возможности

- Залы и тамады с ценой, вместимостью и рейтингом, сортировка по рейтингу, цене и расстоянию
- Подбор зала по числу гостей и бюджету (`/budget`)
- Отзывы и оценки, избранное
- Поиск (`/search`) и три ближайших зала по геолокации (`/nearby`)
- Топ, случайный зал, статистика (`/top`, `/random`, `/stats`)

## Бэкенд

Python 3, aiogram 3, SQLite. Таблицы: `users`, `items` (залы и тамады), `reviews`, `favorites`.
Вся логика (поиск, сортировка, расстояние, подбор по бюджету, отзывы, избранное) выполняется на сервере.

## Деплой

Railway, запуск `python bot.py`. База лежит на постоянном диске `/data`, поэтому данные не теряются при перезапуске.
Переменные окружения: `BOT_TOKEN` (токен бота), `DB_PATH` (`/data/toi.db`).

## Запуск локально

```
git clone https://github.com/nrauan93-pixel/TOI.git
cd TOI
pip install -r requirements.txt
echo BOT_TOKEN=токен > .env
python bot.py
```
