# \# Toi Bot 🎉# TOIIM 🎉

Платформа для организации тоя: свадьбы, кыз узату, юбилея. Залы, тамады, музыка, фото и декор с ценами, отзывами и подбором по бюджету в одном месте.

| | Ссылка | Хостинг |
|---|---|---|
| 🌐 Сайт | https://toiim.onrender.com | Render + Neon (PostgreSQL) |
| 🤖 Telegram-бот | https://t.me/toi3_bot | Railway |

Оба продукта работают онлайн без запущенного локального кода.

## Идея

Чтобы организовать той, приходится искать залы и исполнителей по Instagram и чатам, где цены скрыты, а отзывам трудно верить. TOIIM собирает всё в одном каталоге: видно цену, вместимость, рейтинг и отзывы.

## Возможности

**Сайт**
- Каталог залов и исполнителей с фильтрами по городу, категории, числу гостей и бюджету
- Страница услуги с отзывами и заявкой на дату
- Регистрация, личный профиль, избранное, оценки от 1 до 5
- Калькулятор бюджета, админка для модерации

**Бот**
- Залы и тамады с ценой, вместимостью и рейтингом, сортировка по рейтингу, цене и расстоянию
- Подбор зала по числу гостей и бюджету (`/budget`)
- Поиск (`/search`), ближайшие залы по геолокации (`/nearby`)
- Отзывы, избранное, топ, случайный зал, статистика

Данные в каталоге демонстрационные.

## Технологии

- **Сайт:** Python, Django 5.2, Django REST Framework, PostgreSQL (Neon), gunicorn, whitenoise
- **Бот:** Python 3, aiogram 3, SQLite на постоянном диске Railway
- **API для бота:** `/api/services/`, `/api/requests/`, `/api/health/`
- Секреты хранятся только в переменных окружения хостингов

## Запуск бота локально

```
git clone https://github.com/nrauan93-pixel/TOI.git
cd TOI
pip install -r requirements.txt
echo BOT_TOKEN=токен > .env
python bot.py
```
