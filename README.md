# \# Toi Bot 🎉

# 

# \*\*Telegram-бот для выбора места проведения тоя (праздника): залы, тамады, цены, отзывы и расстояние до вас в одном месте.\*\*

# 

# 🤖 \*\*Живая ссылка на бота:\*\* https://t.me/toi3\_bot

# ☁️ \*\*Хостинг:\*\* Railway (бот работает 24/7 на сервере, без запущенного локального кода)

# 

# \---

# 

# \## О проекте

# 

# \### Проблема

# Организация тоя — это десятки звонков и поисков. Нужно сравнить залы по цене и вместимости, прочитать отзывы, понять, как далеко от дома находится место, и найти хорошего тамаду. Информация разбросана по Instagram-страницам, чатам и знакомым.

# 

# \### Решение

# Toi Bot собирает залы и тамад в одном Telegram-боте. Пользователь за пару минут:

# \- смотрит список залов и тамад с ценами, вместимостью и рейтингом;

# \- сортирует их по рейтингу, цене или расстоянию до себя;

# \- вводит число гостей и бюджет и получает залы, которые подходят;

# \- читает отзывы других людей и оставляет свои;

# \- сохраняет понравившиеся варианты в избранное.

# 

# \### Почему Telegram

# Telegram есть у всех, не нужно устанавливать отдельное приложение и регистрироваться. Бот открывается по ссылке и сразу готов к работе.

# 

# \---

# 

# \## Возможности

# 

# | Команда | Что делает |

# |---|---|

# | `/start` | Главное меню с кнопками |

# | `/halls` | Список залов с сортировкой по рейтингу, цене и расстоянию |

# | `/hosts` | Список тамад |

# | `/budget` | Подбор зала по числу гостей и бюджету |

# | `/favorites` | Избранные залы и тамады |

# | `/search` | Поиск по названию или описанию (например, «шанырак») |

# | `/nearby` | Три ближайших зала (нужна геолокация) |

# | `/myreviews` | Мои отзывы |

# | `/top` | Топ-3 зала по рейтингу |

# | `/random` | Случайный зал |

# | `/stats` | Статистика: сколько залов, тамад и отзывов |

# | `/about`, `/help` | О боте и справка |

# 

# Пользователь также может поделиться геолокацией, чтобы видеть расстояние до каждого зала, поставить оценку от 1 до 5 с текстовым отзывом, добавлять места в избранное и убирать их оттуда.

# 

# \---

# 

# \## Как это работает

# 

# ```

# Пользователь в Telegram

# &#x20;       │

# &#x20;       ▼

# &#x20;  Telegram Bot API

# &#x20;       │  (long polling)

# &#x20;       ▼

# &#x20;  bot.py (aiogram 3)  ←── запущен на Railway

# &#x20;       │

# &#x20;       ▼

# &#x20;  SQLite (toi.db) на постоянном диске /data

# ```

# 

# 1\. Пользователь пишет боту в Telegram.

# 2\. Telegram передаёт сообщение серверу, где запущен бот (Railway).

# 3\. Бот обрабатывает команду на сервере: читает и записывает данные в базу.

# 4\. Ответ с кнопками и карточками возвращается пользователю.

# 

# Вся логика (поиск, сортировка, расчёт расстояния, подбор по бюджету, отзывы, избранное) выполняется на сервере, а данные хранятся в базе данных.

# 

# \---

# 

# \## Бэкенд и база данных

# 

# \*\*Стек:\*\* Python 3, aiogram 3, SQLite, python-dotenv.

# 

# \*\*Таблицы базы данных:\*\*

# 

# | Таблица | Поля | Назначение |

# |---|---|---|

# | `users` | id, name, lat, lon | Пользователи и их геолокация |

# | `items` | id, kind, name, price, capacity, lat, lon, address, info | Залы (`venue`) и тамады (`host`) |

# | `reviews` | id, item\_id, user\_id, user\_name, rating, text | Отзывы и оценки |

# | `favorites` | user\_id, item\_id | Избранное пользователей |

# 

# \*\*Серверная логика:\*\*

# \- расчёт расстояния от пользователя до зала по формуле гаверсинусов;

# \- средний рейтинг и количество отзывов считаются запросом `AVG` / `COUNT`;

# \- подбор по бюджету: зал подходит, если вместимость не меньше числа гостей и `цена × гости` не больше бюджета;

# \- пошаговые диалоги (отзыв, подбор бюджета, поиск) реализованы через конечные автоматы (FSM) aiogram;

# \- при первом запуске бот сам создаёт таблицы и заполняет их демонстрационными данными.

# 

# > Сейчас в базе демонстрационные залы и тамады. Перед реальным запуском они заменяются настоящими заведениями Алматы.

# \---

# \## Хостинг и деплой

# 

# Бот развёрнут на \*\*Railway\*\* и работает независимо от компьютеров разработчиков.

# 

# \- Код берётся из этого репозитория и запускается командой `python bot.py`.

# \- Зависимости устанавливаются из `requirements.txt`.

# \- \*\*Постоянный диск (volume) `/data`\*\* хранит файл базы `toi.db`, поэтому избранное, отзывы и геолокация пользователей не теряются при перезапуске и новых деплоях.

# \- Секреты (токен бота) хранятся в переменных окружения на сервере и не попадают в репозиторий.

# 

# \*\*Переменные окружения:\*\*

# 

# | Переменная | Назначение |

# |---|---|

# | `BOT\_TOKEN` | Токен бота от @BotFather |

# | `DB\_PATH` | Путь к файлу базы (на сервере `/data/toi.db`, локально `toi.db`) |

# 

# \*\*Как задеплоить самому (Railway CLI):\*\*

# 

# ```

# npm i -g @railway/cli

# railway login

# railway init

# railway up

# railway variables --set "BOT\_TOKEN=ваш\_токен"

# railway variables --set "DB\_PATH=/data/toi.db"

# railway volume add --mount-path /data

# railway up

# railway logs

# ```

# 

# В логах должны появиться строки `Start polling` и `Run polling for bot @toi3\_bot`.
