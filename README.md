# Toi Bot 🎉

Telegram-бот для выбора места проведения тоя (праздника).

## Идея
Организовать той непросто: нужно сравнить залы, цены, отзывы и найти тамаду. Бот собирает всё это в одном месте и помогает быстро выбрать подходящий вариант.

## Возможности
- /start — главное меню
- /halls — список залов
- /hosts — тамады
- /budget — подбор по бюджету
- /favorites — избранные залы и тамады
- /search — поиск залов и тамады по названию или описанию
- /nearby — три ближайших зала (нужна геолокация)
- /help — помощь
- /about — о боте

## Технологии
- Python 3
- aiogram 3
- SQLite (toi.db)

## Запуск
1. Установить зависимости: pip install aiogram python-dotenv
2. Создать файл .env и указать токен: BOT_TOKEN=твой_токен
3. Запустить: python bot.py
